# Förhandsorder – programuppdateringar

Det här publika repot är endast distributionskanal för färdiga versioner av
Förhandsorder. Programmet använder GitHub Releases härifrån för att kontrollera,
hämta och verifiera nya programversioner.

## Ingen butiksdata

Här får aldrig finnas:

- försäljningshistorik, artikeldata, priser eller kampanjvolymer
- importerade KOF-/SOF-filer eller sparade inköpsbeslut
- SQLite-databaser, Excel-filer eller PDF-underlag
- cookies, browserprofiler, autentiseringsuppgifter eller sessionsvärden

All sådan data ligger kvar lokalt på respektive användares dator. En
programuppdatering ersätter endast programkod och rör inte den lokala databasen.

## Innehåll

Färdiga installationspaket, `update-manifest.json` och kontrollsummor publiceras
som GitHub Releases. De ska inte checkas in som vanliga filer i repot.
