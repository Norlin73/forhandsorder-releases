# Säkerhetsgräns

Detta repo är avsiktligt publikt och får därför bara innehålla generella
programfiler. Butiksdata och autentiseringsdata ska stanna i programmets lokala
datakatalog på respektive dator.

Releasepaket tas fram av huvudprojektets särskilda publiceringsverktyg. Verktyget
tar endast emot uttryckligen angivna programfiler, kontrollerar arkivinnehåll och
vägrar kända dataformat innan något laddas upp.

Rapportera omedelbart till repoägaren om en release eller commit verkar innehålla
butiks- eller sessionsdata.
